# 华水校园生活服务平台 · 前端

基于 Vue 3 + TypeScript + Vite + Element Plus 生成，对应后端 13 个微服务模块的 HTTP 接口。

## 启动

```bash
cd huashui-ui
pnpm install
pnpm dev
```

开发服务器默认 `http://localhost:5173`，`/api` 请求会代理到网关 `http://127.0.0.1:8080`。

## 页面结构

- 登录：账号/邮箱登录，图形验证码
- 总览：考勤统计、我的宿舍、最新通知
- 认证权限：菜单管理、角色管理、个人中心
- 系统管理：字典类型/数据、参数配置、三类日志
- 宿舍管理：校区/楼栋/房间/住宿记录/我的宿舍
- 生活服务：水费、电费、缴费记录
- 考勤请假：我的考勤、考勤管理、请假管理
- 维修与保洁：我的报修、报修管理、我的维修、保洁任务、任务模板
- 评价问卷：问卷管理、待我评价、评价统计
- 消息公告：公告管理、通知中心、我的消息

## 说明

- 统一响应拦截器在 `src/api/http.ts`
- 后端接口按模块封装在 `src/api/index.ts`
- 通用 CRUD 页面组件在 `src/components/SchemaCrud.vue`
- 登录态使用 Sa-Token 默认请求头 `satoken`
