# 华水校园生活服务平台 · 本地部署指南

> 适用场景：从 GitHub 克隆项目后，在本地 Windows / macOS / Linux 环境快速启动。

> 安全约定：本指南和项目内不提供任何真实密码。所有密码由部署者自行设置。

---

| 软件 | 推荐版本 | 说明 |
|------|----------|------|

| Maven | 3.9+ | 后端构建 |

## 三、初始化数据库

### 1. 创建数据库和表

项目已提供建表脚本：

```text
docs/sql/init-schema.sql
```

登录 MySQL 后执行：

```bash
mysql -u root -p < docs/sql/init-schema.sql
```

该脚本只创建数据库和表，不创建用户、不设置密码。

### 2. 自行创建数据库用户

示例：

```sql
CREATE USER 'huashui_app'@'%' IDENTIFIED BY '你的自定义密码';
GRANT ALL PRIVILEGES ON huashui_rbac.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_system.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_storage.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_dormitory.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_utility.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_evaluation.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_attendance.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_leave.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_task.* TO 'huashui_app'@'%';
GRANT ALL PRIVILEGES ON huashui_message.* TO 'huashui_app'@'%';
FLUSH PRIVILEGES;
```

## 四、启动基础中间件

### 1. Nacos

启动 Nacos 后，在浏览器打开：

```text
http://127.0.0.1:8848/nacos
```

项目各模块默认从 Nacos 读取共享配置。你需要创建以下配置：

| Data ID | 用途 |
|---------|------|
| `shared-mysql.yml` | MySQL 数据源 |
| `shared-redis.yml` | Redis 连接 |
| `shared-token.yml` | Sa-Token 配置 |
| `shared-springdoc.yml` | 接口文档配置 |
| `shared-minio.yml` | MinIO 配置（storage 模块） |
| `shared-smtp.yml` | 邮箱验证码配置（auth 模块） |

#### `shared-mysql.yml` 示例

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://127.0.0.1:3306/huashui_rbac?useUnicode=true&characterEncoding=utf8mb4&serverTimezone=Asia/Shanghai
    username: huashui_app
    password: 你的自定义密码
```

> 不同模块使用不同数据库，建议在 Nacos 中按服务或环境区分数据库名；也可以使用项目的 `hs.jdbc.db` 配置辅助拼接。

#### `shared-redis.yml` 示例

```yaml
spring:
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      password:
```

#### `shared-token.yml` 示例

```yaml
sa-token:
  token-name: satoken
  timeout: 2592000
  active-timeout: -1
  is-concurrent: true
  is-share: false
  token-style: uuid
  is-read-cookie: false
```

### 2. Redis、RabbitMQ、MinIO

可使用项目提供的 `docker-compose.yml`，但建议先将其中的账号密码替换为你自己的环境变量或 `.env` 文件。

#### RabbitMQ 延迟消息交换机插件

评价问卷定时开始/结束、校园公告定时发布等场景会用到延迟消息。`docker-compose.yml` 已通过 `rabbitmq/Dockerfile` 在官方 `rabbitmq:3.13-management-alpine` 基础上预装了 `rabbitmq_delayed_message_exchange` 插件（提供 `x-delayed-message` 交换机类型）。

启动时使用 `--build` 构建镜像（构建过程需要联网下载插件）：

```bash
docker compose -f docker-compose.yml up -d --build
```

> 插件版本与 RabbitMQ 版本对应关系：RabbitMQ 3.13.x → 插件 `3.13.0`。

**已有运行中的容器、不想重建时**，可手动安装插件：

```bash
# 1. 下载插件（版本需与 RabbitMQ 匹配）
wget -O /tmp/rabbitmq_delayed_message_exchange-3.13.0.ez \
  https://github.com/rabbitmq/rabbitmq-delayed-message-exchange/releases/download/v3.13.0/rabbitmq_delayed_message_exchange-3.13.0.ez

# 2. 复制进容器并启用
docker cp /tmp/rabbitmq_delayed_message_exchange-3.13.0.ez huashui_rabbitmq:/opt/rabbitmq/plugins/
docker exec huashui_rabbitmq rabbitmq-plugins enable rabbitmq_delayed_message_exchange

# 3. 重启并验证
docker restart huashui_rabbitmq
docker exec huashui_rabbitmq rabbitmq-plugins list -e | grep delayed
# 应看到 [E*] rabbitmq_delayed_message_exchange 3.13.0
```

## 五、配置后端服务

### 1. 修改每个服务的数据库密码

服务通过 Nacos 的 `shared-mysql.yml` 获取数据源，密码已在 Nacos 配置中设置。

部分服务直接写有本地数据源，请检查这些文件的 `application.yml`：

```text
huashui-evaluation/src/main/resources/application.yml
huashui-message/src/main/resources/application.yml
huashui-task/src/main/resources/application.yml
huashui-utility/src/main/resources/application.yml
```

将这些文件中出现的数据源用户名和密码改为你自己创建的账号密码。

### 2. 修改 Nacos 地址和密码

各模块 `application.yml` 中 Nacos 地址默认：

```yaml
spring:
  cloud:
    nacos:
      server-addr: 127.0.0.1:18848
      username: nacos
      password: 你的Nacos密码
```

## 六、启动后端服务

建议启动顺序：

1. Nacos
2. MySQL、Redis、RabbitMQ
3. `huashui-auth`
4. `huashui-gateway`
5. 其他业务服务

### 单模块启动

```bash
cd huashui-auth
mvn spring-boot:run
```

```bash
cd huashui-gateway
mvn spring-boot:run
```

### 批量编译

```bash
mvn -DskipTests clean package
```

或按需编译：

```bash
mvn -pl huashui-auth,huashui-dormitory,huashui-gateway -am -DskipTests package
```

## 十、常见问题

### 1. 前端 `5173` 端口启动失败

当前前端默认使用 `4173` 端口，避免 Windows 端口排除范围占用 `5173`。

### 2. 后端提示数据库连接失败

检查：

- MySQL 是否启动
- 数据库是否执行了 `docs/sql/init-schema.sql`
- 用户名密码是否与 Nacos / `application.yml` 中一致
- 数据库用户是否拥有对应库权限

### 3. Nacos 配置读取失败

检查 Nacos 地址、用户名、密码，以及 Data ID 是否创建正确。

### 4. 文件上传失败

检查 `shared-minio.yml` 是否配置，以及 MinIO 是否启动。
