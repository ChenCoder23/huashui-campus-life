## 二、WSL 网络配置（重要！）

为了让 `localhost` 能访问 WSL 里的容器，需配置镜像网络模式。

**PowerShell 执行：**

```powershell
@"
[wsl2]
networkingMode=mirrored
"@ | Out-File -FilePath "$env:USERPROFILE\.wslconfig" -Encoding utf8

wsl --shutdown
```

然后重新打开 WSL 终端。

## 三、启动本地中间件

### 3.1 下载 docker-compose.yml

将项目中的 `docker-compose.yml` 放到 `C:\Users\<你的用户名>\` 目录下。

### 3.2 启动

打开 WSL 终端：

```bash
cp /mnt/c/Users/$USER/docker-compose.yml /tmp/dc.yml
docker compose -f /tmp/dc.yml up -d
```

### 3.3 验证

```bash
docker ps
```

## 四、连接云服务（SSH 隧道）

云服务器 `43.143.130.165` 部署了 **MySQL** 和 **Nacos**，不直接暴露端口，需通过 SSH 隧道连接。

### 4.1 获取服务器账号

找管理员获取 SSH 用户名和密码。

### 4.2 启动隧道

将以下内容保存为 `启动华水隧道.bat`，双击运行，输入密码后保持窗口打开：

```bat
@echo off
chcp 65001 >nul
title Huashui Tunnel
echo MySQL  -> localhost:3308
echo Nacos  -> localhost:8848
echo.
ssh -L 3308:localhost:3306 -L 8848:localhost:8848 ubuntu@43.143.130.165 -N
pause
```

### 4.3 验证

- Nacos：浏览器打开 `http://localhost:8848/nacos`
- MySQL：DataGrip 连接 `localhost:3308`

## 八、常见问题

**Q: localhost 打不开 WSL 容器？**

检查 `C:\Users\<用户名>\.wslconfig` 是否存在且内容为 `networkingMode=mirrored`。修改后需 `wsl --shutdown` 重启。

**Q: 隧道连不上？**

检查服务器 IP 和安全组是否开了 22 端口。

**Q: 容器端口冲突？**

本地 3306 被旧 MySQL 占用，所以云 MySQL 映射到 3308，本地 MySQL 映射到 3309。
