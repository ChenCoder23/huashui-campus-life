# 前端图片 / Logo 占位说明

## 1. 浏览器图标
- 路径：`huashui-ui/public/favicon.svg` 或 `huashui-ui/public/favicon.png`
- 格式：SVG 或 PNG
- 建议尺寸：64 × 64 px

## 2. 侧边栏 / 登录页 Logo
- 路径：`huashui-ui/src/assets/logo.svg`
- 格式：SVG，透明背景
- 建议尺寸：512 × 512 px

## 3. 登录页轮播图
- 目录：`huashui-ui/src/assets/login-carousel/`
- 数量：3 ~ 6 张
- 格式：JPG / JPEG
- 建议尺寸：1920 × 1080 px 或 2560 × 1440 px
- 单张大小：建议不超过 1 MB

## 4. Dashboard 校园横幅
- 路径：`huashui-ui/src/assets/login-carousel/1552382688_5438_thumb.jpg`
- 格式：JPG
- 建议尺寸：1200 × 400 px
- 建议大小：不超过 300 KB

## 5. 用户头像
- 由用户上传，不走本地占位
- 建议格式：JPG / PNG / WebP
- 建议尺寸：200 × 200 px 以上
- 建议大小：不超过 5 MB

## 6. 公告封面 / 附件
- 可选路径：`huashui-ui/src/assets/notice-placeholder.jpg`
- 格式：JPG
- 建议尺寸：800 × 450 px
- 建议大小：不超过 500 KB
