## 四、已知问题汇总

### 4.1 编译错误（会导致 `mvn compile` 失败）
1. `huashui-evaluation`：
   - `EvaluationResultController` 引用不存在的 `EvaluationStatisticsService`、`QuestionnaireStatisticsVO`、`QuestionStatisticsVO`；
   - `EvaluationQuestionnaireServiceImpl` 误用 Spring 注解类 `ResponseStatus`。

### 4.2 Feign 契约漂移（运行时 404 / 服务发现失败）
- 服务名 `huashui-user` 不存在（auth 模块注册名是 `huashui-auth`）。
- 多处 Feign 路径缺少 `/inner` 前缀，与目标 Controller 不匹配。
- `RoomClient.getRoomDetailInfoById` 客户端声明 `RoomDetailVO`，服务端返回 `RoomVO`，且路径多一段 `/room`。

### 4.3 空实现 / TODO
- `huashui-auth`：`myInfoController` 类体为空。
- ~~`huashui-message`~~：公告详情接口已实现。
- ~~`huashui-leave-service`~~：MQ 通知已补齐，并新增保洁请假自动写考勤（Feign 同步）。
- `huashui-dormitory`：`getRoomPage` 返回 null（房间列表失效）、`getMyDorm`/`getMyRoommates` 为空壳。

### 4.4 其他 bug 风险
